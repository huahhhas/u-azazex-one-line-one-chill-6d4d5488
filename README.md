## The line

> The baby monitor crackled, and in my own voice it whispered not to open the nursery door because it was already inside with her.

## How it works

`main.py` writes that single line to `/output/entry.txt` and prints it.
`entry.txt` holds the exact same line. One sentence, one line, 128
characters — inside the 1–200 character gate.
